# consulta-funcionario
Recentemente desenvolvi um sistema simples de consulta de funcionários utilizando Python, Flask e MySQL. 
O projeto permite buscar um colaborador pelo código (RE) e verificar se está presente ou ausente, exibindo também seus dados detalhados em uma tabela. 
Durante o desenvolvimento, trabalhei com: Flask para criar a aplicação web e gerenciar requisições POST e GET. 
Jinja2 para renderização dinâmica do HTML, mostrando mensagens e dados do funcionário de forma condicional. 
MySQL para armazenar e consultar os dados, aprendendo a conectar e executar queries com segurança. 
HTML/CSS para estruturar e estilizar a interface de forma clara e responsiva.
